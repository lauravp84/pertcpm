Como o cálculo funciona

1 · Caminho de ida (forward pass)

Percorra a rede do início para o fim. O ES de uma atividade é o maior EF entre suas predecessoras (zero, se não houver nenhuma). O EF é ES + duração. O maior EF da rede é a duração do projeto.

2 · Caminho de volta (backward pass)

Agora do fim para o início. O LF da última atividade é a duração do projeto; nas demais, é o menor LS entre as sucessoras. O LS é LF − duração.

3 · Folgas

Folga total = LS − ES = LF − EF: quanto a atividade pode atrasar sem atrasar o projeto. Folga livre = menor ES das sucessoras − EF: quanto pode atrasar sem atrapalhar a próxima atividade. Folga total zero = atividade crítica.

4 · PERT (três estimativas)

Quando a duração é incerta: te = (o + 4m + p) / 6 e σ² = ((p − o)/6)². A duração do projeto vira uma distribuição aproximadamente normal, com média igual à soma dos te críticos e variância igual à soma das variâncias críticas — daí sai a probabilidade de cumprir qualquer prazo.

5 · Compressão

Para encurtar o projeto só adianta acelerar atividades críticas. Comprime-se sempre a de menor custo por período; quando surge um segundo caminho crítico, é preciso comprimir os dois ao mesmo tempo. O prazo ótimo é o que minimiza custo direto + custo indireto.

Convenção de datas

Os valores ES/EF/LS/LF estão em fim de período: uma atividade de 5 dias que começa no instante 0 termina no instante 5. No Gantt, o dia 1 do calendário corresponde ao instante 0.
